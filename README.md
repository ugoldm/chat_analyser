# Chat Analyser

Проект разделён на две папки:

- `python_pipeline/` — полностью автономный Python-пайплайн для ежедневной выгрузки, анализа и генерации HTML-отчётов.
- `n8n_pipeline/` — код и инструкции для реализации того же сценария внутри `n8n` через Python/LLM nodes.

Текущая Telethon-сессия Telegram хранится в корне проекта как `telegram_user.session` и используется Python-пайплайном по умолчанию.
